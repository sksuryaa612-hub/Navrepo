# 🌐 Simple Navigation Bar

This repository contains a simple navigation bar created using HTML and CSS. It is a beginner-friendly project that demonstrates the basics of creating a website navigation menu and styling it with CSS.

## ✨ Features

- Simple HTML structure
- Basic CSS styling
- Center-aligned navigation links
- Hover effect on links
- Easy to understand and customize

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚀 Purpose

This project helps beginners learn how to create and style a navigation bar for a website using HTML and CSS.
